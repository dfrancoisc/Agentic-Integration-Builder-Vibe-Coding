Pipeline
1
Builder
Asks the agent to create a new production, DTL, BPL, or routing rule via the chatbot
2
Agent
Creates the class definition via $System.OBJ.Compile() using standard %Dictionary APIs
3
IRIS
%SourceControl hook fires automatically, exports the class definition to the local Git working directory. Change attributed to the authenticated user.
4
Builder
Commits the exported class definitions and pushes to the GitLab remote repository
5
GitLab CI
CI/CD pipeline triggers: lint class definitions, validate configuration, run integration tests
6
Pipeline
On success: deploy to staging environment, then promote to production after approval
