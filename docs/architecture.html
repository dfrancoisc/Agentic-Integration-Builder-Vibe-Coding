ChatService Run Loop Custom
Editor.ChatService (SSE streaming path)
Custom iteration loop replaces %AI.Agent.Run():
  • Calls agent.Chat() per iteration (avoids empty-text Bedrock bug)
  • ChatWithRetry: 30/60/90s exponential backoff on rate limit
  • Inter-iteration cooldown: 3-5s to stay under TPM
  • Fabrication guard: detects text-only claims, forces tool use
  • Monitor: 300s wall-clock, 100K token budget, SSE keepalives

RAG Catalogs (IRIS Vector Search — runtime-registered KnowledgeBases)
Catalog.Builder Indexer
extends %RegisteredObject
Walks %Dictionary for Ens.Host / HS.* classes. Embeds descriptions with FastEmbed (AllMiniLML6V2, 384-dim). Persists to SQL vector tables.
  • search_ens — Ens.* hosts, adapters, messages
  • search_hs — HS.* transformations, FHIR mappers
Seeds from InterSystems_IRIS_Health_Complete_Class_Catalog.xlsx
Catalog.Attach Runtime Wiring
extends %RegisteredObject
Called by Manager.Build() at request time. Registers search_ens and search_hs as %AI.RAG KnowledgeBase tools on the agent's ToolManager.
Uses %AI.ToolMgr.ExecuteTool() to query KBs (not SQL EMBEDDING — FastEmbed path).

Persistence Layer
Data.Connection %Persistent
SQL: AgenticInterop_Data.LLMConnection
LLM provider metadata: name, provider type (bedrock/anthropic/azure-openai/...), model, region, base URL, max tokens, enabled, default.
Secrets in IRIS Secured Wallet (never in table). LastTestOk/LastTestError for health semaphore.
Overlay Tables 3 classes
all %Persistent + %JSON.Adaptor
  • Data.AgentOverride — custom instructions, temperature, MCP/skill lists per agent class
  • Data.MCPOverride — custom name, description, toolset list per MCP class
  • Data.ToolSetOverride — custom tool manifest per toolset class
Keyed by ClassName. Merged on top of shipped defaults by Editor.Overlay.
Data.AuditLog %Persistent
SQL: AgenticInterop_Data.AuditLog
Every REST call logged: username, namespace, session ID, job, method, path, status code, request/response size, duration, error text.
Indexed by (Username, Created), (Path, Created).
