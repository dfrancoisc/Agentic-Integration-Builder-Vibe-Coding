AI Chatbot Phase 2

The streaming conversation surface for the IRIS for Health copilot ships in Phase 2 of the build plan (see docs/PLAN.md).

Right now this page acts as the namespace anchor — the moment you open it from the Interop Editor, the active namespace (the one your Production Configuration / Rule Editor / etc. is operating on) is captured and displayed at the top. Every chat message in Phase 2 will be scoped to this namespace, and any tool the agent invokes will run with the same namespace privileges and visibility you have.

Why this matters: the same question can have different answers in different namespaces (e.g. "show me running productions" against USER vs HSCUSTOM), so the chatbot must always know where it is before it speaks.

What's wired right now:

  • Agent class AgenticInterop.Agent.HealthInterop — router prompt + Parameters MCPS / SKILLS
  • 4 MCPs (Production, Transform, Testing, Catalog) and 9 Skills, configurable from AI Configuration
  • REST endpoints under /api/agentic/editor/* with full %Dictionary roundtrip
  • JWT auth via the Interop SPA — no second login required

In the meantime, configure tools and skills in AI Configuration (cross-namespace).
